# Contract generator

The final export remains one PDF containing separate documents: the main contract, the applicable hosting/technical appendix, and the GDPR subcontracting agreement when required. Each document starts on a new page, has its own title and continuation headers, and restarts page numbering at 1. All pages of the accepted quote follow these documents unchanged.

The generator reads the Markdown templates in `templates/`. The main contract is `templates/contract_template.md`, with `templates/gdpr_subcontracting_agreement_template.md` and `templates/hosting_appendix_template.md` providing the applicable supporting documents. The G0–G8 setup guidance is represented by the editor configuration and is not included in an exported contract. `shared/contract-template.json` provides stable mappings for older drafts.

The editor uses the template's stable choice identifiers and semantic variable names. `shared/utils/contract-configuration.ts` defines labels, allowed values, dependencies, and required variables. It covers client status, subscribed services, development and rights, hosting, SLA and support, maintenance and security, backups, duration, reversibility, and data processing. Branches disappear when their triggering service or option is inactive; their saved values are retained for later editing. The sales-context selector from the template is omitted at the user's request; the other consumer-specific fields and clauses remain.

`shared/utils/contract-document.ts` composes the client document from the active configuration. It excludes unselected operational clauses, recalculates article numbers and annex references, includes only selected technical measures, and excludes professional late-payment penalties from consumer contracts. General clauses remain. At the user's request, intellectual property is a fixed clause: all code produced under the contract belongs to the client, who may request the source code at any time. The former licence / assignment choices, source-delivery toggle, rights annex, and assignment approval check are omitted, including for existing drafts. Data processing requires a completed data-processing annex, whose letter follows the active annex order.

Export requires a contract reference and date, quote reference and issue date, an attached quote PDF, all active variables, consistent options, and the retained checks from G8. Unqualified data processing, missing SLA values, incomplete backup retention, unresolved placeholders, and missing applicable consumer / data-processing checks block export. Checks are cleared whenever the contract's fields, options, or quote change. Drafts can still be saved at any stage. The downloaded PDF fixes the chosen clauses and values and appends every page of the quote.

The contract reference is generated as `CTR-` followed by the quote reference, for example `DEV-2026-0042` becomes `CTR-DEV-2026-0042`. It follows changes to the quote reference, including PDF extraction, until the user supplies a custom contract reference. Opening an existing draft with an empty contract reference also suggests the generated value; existing custom values are preserved.

Contracts use schema version 2. Opening a version 1 draft copies its known values to semantic fields, retains **all** original values and the quote, and leaves the new choices and checks for review. Original values remain visible in the editor. Opening does not update the database; saving persists the upgraded draft. Version 1 drafts cannot be newly exported until reviewed under the updated configuration. No database migration is needed because contracts are stored as JSON.

Manual verification used headless Chrome with an isolated database: toggling hosting revealed its fields, inactive backup fields stayed hidden, numeric input produced no runtime errors, and uploading a real PDF filled both quote metadata fields. The form was visually checked at 1280 × 900 in dark mode and 390 × 844 in light mode, with no horizontal overflow on mobile. Automated coverage includes client profiles, conditional annexes and renumbering, export checks, old-draft preservation, PDF pagination and attachments, and authenticated save/reopen behavior.
